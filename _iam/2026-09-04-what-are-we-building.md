Wire Finance is not being built as a collection of disconnected labs.

The goal is to create a realistic security environment that grows with the organisation and allows us to explore how identity, devices, cloud services, monitoring, detection, and incident response all work together.

We will begin with the organisation's identity foundation, defining who users are, what access they should receive, and how that access changes throughout their time with the company.

From there, the environment will gradually expand to include:

- Microsoft Entra ID for identity and access management
- Microsoft Intune for endpoint management
- Microsoft Defender for endpoint and email security
- Microsoft Sentinel for SIEM and security operations
- On-premises Active Directory
- Hybrid identity
- Logging and monitoring
- Detection engineering
- Threat hunting
- Incident investigation and response

As the environment becomes more mature, we will also introduce realistic business and security scenarios that allow us to see how these technologies interact when something goes wrong.

The objective is not simply to install tools.

It is to understand how a modern organisation is designed, how its security controls support the business, and how a SOC can detect, investigate, and respond to threats across the environment.

In short, we are building a company, securing it, and learning from everything that happens along the way.
